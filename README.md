# Системи Штучного Інтелекту (Artificial Intelligence Systems)

Лабораторні роботи з курсу «Методи і системи штучного інтелекту» (ЛНУ імені Івана Франка).
Єдиний веб-додаток з динамічним лінивим завантаженням (lazy-loading) лабораторних робіт та модульною архітектурою з переикористовуваними компонентами в `src/common/`.

---

## Запуск проєкту

### Вимоги
- [Node.js](https://nodejs.org/) (v18+) або [Bun](https://bun.sh/) (v1.0+)

### Команди для запуску
```bash
# Запуск локального сервера розробки
bun run dev
# або
npm run dev

# Збірка продакшн версії
bun run build
# або
npm run build
```
Після запуску відкрийте у браузері: `http://localhost:3000`

## Лабораторна 1: Сліпий пошук на графах (BFS)

### Функціонал:
1. **3 фіксовані пресети графів (>30 вершин, >30-40 ребер, >5 рівнів гілок):**
   - Дерево (Tree)
   - Звичайний неорієнтований граф з циклами (Undirected)
   - Орієнтований граф з напрямленими дугами (Digraph)
2. **Параметри експерименту:**
   - Вибір початкової ($S$) та цільової ($G$) вершин + кнопка швидкої заміни ($S \leftrightarrow G$).
   - Порядок обходу суміжних вершин: за зростанням ID, за спаданням ID, або геометрично за годинниковою стрілкою.
   - Редагування графа прямо на полотні (додавання/видалення вершин, ребер, дуг).
3. **Метрики для звіту:**
   - Знайдений шлях та його довжина (кількість ребер).
   - Кількість розкритих вершин.
   - Кількість використаних циклів.
   - Час виконання пошуку (мс).
   - Жива черга FIFO.
   - Протокол кроків (Trace log) з експортом у CSV.
   - Знімок графа у форматі PNG для вставки у звіт.

## Як додати наступну лабораторну (Лаб 2, 3...)

1. Створіть директорію `src/labs/2-heuristic-search/`.
2. Реалізуйте клас, що імплементує інтерфейс `LabModule` (з `src/types.ts`), імпортуючи спільні компоненти з `@common/` (або `src/common/`).
3. Зареєструйте нову лабораторну у `src/labs/registry.ts`:
   ```ts
   {
     id: '2-heuristic-search',
     title: 'Лабораторна 2: Евристичний пошук (A*)',
     shortTitle: 'Лаб 2: A*',
     badge: 'Lab 2',
     loader: async () => {
       const module = await import('./2-heuristic-search/index');
       return new module.default();
     }
   }
   ```
Вона автоматично з'явиться в меню та завантажуватиметься ліниво
